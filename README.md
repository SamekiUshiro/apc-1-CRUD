# apc-1-CRUD

🎯 Objetivo Geral
Implementar um sistema de cadastro que permita inserir, consultar, atualizar e remover registros, aplicando os conceitos estudados na disciplina.

🧩 Requisitos Funcionais
O programa deve atender integralmente aos seguintes requisitos:
a) Estrutura do Programa
O código deve conter exclusivamente a função main().
Não é permitido criar funções auxiliares.
A organização lógica deve ser feita utilizando estruturas de decisão e repetição.
b) Menu Principal
Implementar um menu principal interativo, exibido de forma clara e organizada.
O menu deve permitir a seleção das funcionalidades por meio de opções numéricas.
O programa deve permanecer em execução até que o usuário escolha explicitamente a opção de saída.
c) Funcionalidades (CRUD)
O sistema deve implementar as seguintes operações: Cadastrar registro, Listar registros, Buscar registro pelo identificador único, Atualizar registro e Remover registro.
O identificador deve ser único e validado no momento do cadastro.
d) Validação de Entrada de Dados
Todas as entradas devem ser validadas.
O programa deve impedir identificadores duplicados, valores inválidos, operações em posições inexistentes e ações quando não houver registros cadastrados.
O sistema deve tratar adequadamente tentativas de acesso inválido, exibindo mensagens claras ao usuário.
e) Armazenamento de Dados
Deve ser utilizada ao menos uma struct personalizada (ex.: alunos, produtos, livros, músicas, etc.).
O sistema deve utilizar vetor de estruturas com no mínimo 10 posições.
Deve haver controle explícito da quantidade atual de registros cadastrados.
A remoção de registros deve manter a consistência do vetor.
👥 Trabalho em Grupo
O trabalho poderá ser realizado em grupo de até 2 integrantes. A participação de ambos deve ser comprovável por commits. Cada integrante deve submeter o link do repositório. O projeto deve compilar e executar corretamente no momento da avaliação.

📂 Entrega do Projeto
O projeto deve conter:
Repositório no GitHub;
Commits organizados e coerentes com a evolução do projeto;
Aplicação executável localmente.
📊 Critérios de Avaliação
A avaliação será realizada com base na rubrica disponibilizada na atividade, a qual estabelece os critérios e os níveis de desempenho considerados na correção.
